## project Description
This is a simple interactive web page bulit using HTML,CSS and javaScript.The page includes a button that changes text and its colour every time the button is clicked.

## Features
.responsive design
.Hover effect
.Button click interaction 
.Text updates on every click
.text color changes on every click
.clean and simple user interface

##Technologies Used
.HTML
.CSS
.javaScript

## How to run the project
-download or clone the project.
-open the project folder in vs code.
-open the index.html file in your web browser.

## project structure
index.html-web page structure
style.css-page styling
script.js-interactive functionality
