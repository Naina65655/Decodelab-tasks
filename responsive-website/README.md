## project description
This is a simple and responsive web page created using HTML,CSS.The webpage adjusts its layout to provide a good user experience on desktops, tablets, and mobile devices.

## Features
- responsive design for all screen sizes
- clean and modern user interface
- interactive buttons
- hover effects
- easy navigation
- lightweight and fast loading

## Technologies used
- HTML
- CSS 

## Project Structure

## How to run 
1. Download or clone this repository.
2. Open the project folder.
3. Double-click index.html or open it in any web browser.

This project was created to practice responsive web design and improve
