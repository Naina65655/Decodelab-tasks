# Static Web Page Using HTML and CSS

## Project Overview
This project is a simple static web page built using HTML and CSS. It demonstrates the fundamentals of web development, including semantic HTML elements, headings, sections, images, and CSS styling to create a clean and responsive layout.

## Features
- Semantic HTML structure
- Header, navigation, main content, and footer
- Multiple content sections
- Responsive image
- Card-based content layout
- Simple navigation menu
- Clean and readable design

## Technologies Used
- HTML5
- CSS3

## Project Structure

```
static-webpage/
│── index.html
│── style.css
│── images/
│   └── hero.jpg
└── README.md
```

## How to Run
1. Download or clone the project.
2. Add an image named `hero.jpg` inside the `images` folder.
3. Open `index.html` in a web browser.

## Learning Outcomes
- Understanding HTML document structure
- Using semantic HTML elements
- Applying CSS for styling and layout
- Organizing web projects
- Creating a simple responsive webpage
